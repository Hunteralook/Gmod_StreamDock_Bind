Сетевые переключатели

Кнопка показывает текущее состояние и переключает его по нажатию.

Режим переключается перед подключением командой warp-cli mode.

У Happ нет команд для подключения извне, поэтому кнопка запускает и закрывает само приложение. Чтобы при запуске сразу поднималось подключение, включите автоподключение в настройках Happ.

Задачи создаются один раз с подтверждением UAC. После этого кнопка запускает и останавливает zapret без запросов.
