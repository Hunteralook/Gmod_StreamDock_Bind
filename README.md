# Плагины StreamDock

- [GMod Bind](#gmod-bind) — клавиши и кнопки мыши для биндов Garry's Mod.
- [Сетевые переключатели](#сетевые-переключатели-warp-happ-zapret) — кнопки для Cloudflare WARP, Happ и zapret.

# GMod Bind

Плагин эмулирует выбранную клавишу или кнопку мыши через Win32 `SendInput`.
Garry's Mod обрабатывает её как клавишу, назначенную обычной командой `bind`.

## Настройка

`GModBind.exe` не хранится в репозитории. Перед установкой положите его в папку
`com.local.garrysmod.bind.sdPlugin` рядом с `manifest.json`.

1. Запустите StreamDock после установки плагина.
2. Перетащите действие **GMod Bind** из категории **Garry's Mod** на кнопку.
3. Выберите клавишу в инспекторе свойств или нажмите «Нажать клавишу для захвата».
4. Назначьте ту же клавишу в консоли Garry's Mod.

Количество экземпляров **GMod Bind** не ограничено плагином: добавляйте действие
на любое число кнопок и страниц StreamDock, у каждого экземпляра сохраняются свои
настройки. Один экземпляр соответствует одной клавише, кнопке мыши или комбинации
с Ctrl, Shift, Alt и Win.

В списке доступны F1–F24, основные, цифровые, системные, браузерные и
мультимедийные клавиши. Захват также принимает клавиши вне готового списка по их
Windows VK-коду. Если встроенный браузер StreamDock не передаёт редкую клавишу,
VK-код можно указать вручную в диапазоне 1–255 — это диапазон самого Win32 API,
а не лимит количества биндов.

Примеры:

```text
bind f8 "echo STREAMDOCK_OK"
bind f9 "+showscores"
bind mouse4 "+voicerecord"
```

Режим **Удерживать** отправляет отдельные события нажатия и отпускания. Он нужен
для команд, начинающихся с `+`. Режим **Короткое нажатие** автоматически отпускает
клавишу через заданное число миллисекунд.

По умолчанию ввод отправляется только когда активное окно принадлежит
`gmod.exe`, `gmod_win64.exe` или процессу `hl2.exe` из каталога Garry's Mod.

## Ограничения

- Garry's Mod должен быть активным окном.
- StreamDock и игра должны работать с одинаковым уровнем прав. Если игра
  запущена от администратора, Windows может заблокировать ввод от обычного
  процесса StreamDock.
- При выгрузке плагин отпускает все удерживаемые им клавиши.

# Сетевые переключатели (WARP, Happ, zapret)

Плагин `com.local.netswitch.sdPlugin` добавляет в категорию **Сеть** три действия.
Каждая кнопка раз в 3 секунды проверяет состояние, подсвечивается при включённом
подключении и пишет внизу статус: `ВКЛ`, `ВЫКЛ`, `…`, `НЕТ` (программа не найдена),
`НАСТР.` (кнопку нужно настроить) или `ОШИБКА`.

В настройках каждой кнопки можно выбрать, что она делает: переключает, только
включает или только выключает. Количество кнопок не ограничено.

| Действие | Как управляет | Права администратора |
| --- | --- | --- |
| **Cloudflare WARP** | `warp-cli connect` / `disconnect`, перед подключением можно сменить режим (`warp`, `doh`, `warp+doh`, `proxy`, `tunnel_only`) | не нужны |
| **Happ** | запускает и закрывает `Happ.exe`, может открыть ссылку `happ://…` | только если Happ запущен от администратора |
| **zapret** | запускает выбранную стратегию (`general.bat` и т. п.) или службу Windows; останавливает `winws.exe` | нужны |

## Сборка

`NetSwitch.exe` не хранится в репозитории. Запустите `build-netswitch.bat`: он
собирает плагин компилятором C#, который входит в Windows (.NET Framework 4.8),
и проверяет результат командой `NetSwitch.exe --self-test`. Visual Studio и .NET SDK
не нужны.

После сборки скопируйте папку `com.local.netswitch.sdPlugin` в каталог плагинов
StreamDock (обычно `%APPDATA%\HotSpot\StreamDock\plugins`) и перезапустите StreamDock.

## Cloudflare WARP

`warp-cli.exe` ищется в `C:\Program Files\Cloudflare\Cloudflare WARP`. Если WARP
установлен в другое место, укажите путь в настройках кнопки.

## Happ

У Happ нет задокументированных команд для подключения извне, поэтому кнопка
управляет самим приложением: запуск и закрытие. Чтобы подключение поднималось
при запуске, включите автоподключение в настройках Happ.

- `Happ.exe` ищется через обработчик ссылок `happ://` в реестре, затем в
  `%LOCALAPPDATA%\Programs\Happ` и `C:\Program Files\Happ`.
- Сначала Happ получает обычный запрос на закрытие. Если через 3 секунды он ещё
  работает (например, свёрнут в трей), процесс завершается принудительно.
- После закрытия плагин выключает системный прокси Windows, если тот остался
  на `127.0.0.1` или `localhost`. Это можно отключить в настройках кнопки.
- Режим **Открыть ссылку happ://** передаёт ссылку в Happ: подписку, конфиг или
  профиль маршрутизации (`happ://routing/onadd/…`).

## zapret

Рассчитан на сборки вроде [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube),
где стратегии — это `.bat` в корне папки, а обход работает через `bin\winws.exe`.

- **Стратегия (.bat)**: укажите папку zapret. Список стратегий подставится сам,
  файлы `service*.bat` в него не попадают. Остановка завершает `winws.exe`.
- **Служба Windows**: если стратегия установлена как служба через `service.bat`,
  кнопка выполняет `net start` / `net stop` для службы `zapret` (имя можно изменить).

`winws.exe` работает только с правами администратора, поэтому есть два способа запуска:

- **Запрос UAC при каждом нажатии** — по умолчанию.
- **Через планировщик, без UAC** — нажмите «Создать задачи» в настройках кнопки и
  один раз подтвердите UAC. Будут созданы задачи `\StreamDock NetSwitch\Zapret Start`
  и `Zapret Stop` с наивысшими правами. Они запускают скрипты `zapret-start.cmd` и
  `zapret-stop.cmd` из папки плагина, которые плагин перезаписывает перед каждым
  нажатием. Учтите: любая программа, запущенная от вашего пользователя, может
  изменить эти скрипты и тем самым выполнить код с правами администратора. Если
  это неприемлемо, оставьте режим UAC. Удалить задачи можно кнопкой «Удалить задачи».

## Журнал

Плагин пишет действия и ошибки в `netswitch.log` в папке плагина. Заголовки окон и
адреса подписок в журнал не попадают. Файл исключён из git.
