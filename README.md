# GMod Bind для StreamDock

Плагин эмулирует выбранную клавишу или кнопку мыши через Win32 `SendInput`.
Garry's Mod обрабатывает её как клавишу, назначенную обычной командой `bind`.

## Настройка

1. Запустите StreamDock после установки плагина.
2. Перетащите действие **GMod Bind** из категории **Garry's Mod** на кнопку.
3. Выберите клавишу в инспекторе свойств или нажмите «Нажать клавишу для захвата».
4. Назначьте ту же клавишу в консоли Garry's Mod.

Примеры:

```text
bind f8 "echo STREAMDOCK_OK"
bind f9 "+showscores"
bind mouse4 "+voicerecord"
```

Режим **Удерживать** отправляет отдельные события нажатия и отпускания. Он нужен
для команд, начинающихся с `+`. Режим **Короткое нажатие** автоматически отпускает
клавишу через заданное число миллисекунд.

По умолчанию ввод отправляется только когда активное окно принадлежит
`gmod.exe`, `gmod_win64.exe` или процессу `hl2.exe` из каталога Garry's Mod.

## Ограничения

- Garry's Mod должен быть активным окном.
- StreamDock и игра должны работать с одинаковым уровнем прав. Если игра
  запущена от администратора, Windows может заблокировать ввод от обычного
  процесса StreamDock.
- При выгрузке плагин отпускает все удерживаемые им клавиши.
